# 小芽成长

面向 **2026-10-18 满 4 岁** 女儿的每日亲子成长计划 App，参照《3-6岁儿童学习与发展指南》。

## 特点

- **五大领域**：健康 · 语言 · 社会 · 科学 · 艺术
- **时间预算**：工作日约 90 分钟，休息日约 300 分钟
- **认知重点穿插**：汉字、英语、数学、逻辑思维（不是全部，全面发展）
- **性别不设限**：运动、搭建、科学、当队长与艺术创作同样被鼓励；每日 **自选角** 由孩子决定
- **勇敢表达**：针对胆小 / 受欺负不会说，内置「说停 → 走开 → 告诉老师」勇气练习
- **睡前故事提示词**：黑猫警长 / 警察梦 / 互动长故事，一键复制到豆包、元宝、千问
- **视觉**：Apple Liquid Glass + 粉色系（粉色只是喜好，不限制内容）

## 技术

- Next.js 15（App Router，静态导出）
- pnpm
- GitHub Actions → GitHub Pages
- 手机模拟器可直接打开根目录 `index.html`（单文件应用）

## 本地开发

```bash
pnpm install
pnpm dev
# 构建静态站
pnpm build
```

## 部署

推送到 `main` 后由 `.github/workflows/deploy.yml` 自动构建并发布到  
`https://laihaibo.github.io/grow-up/`

远程：`git@github.com:laihaibo/grow-up.git`

## 页面

| 页面 | 说明 |
|------|------|
| 今日 | 每日活动计划、时间花环、勇气练习、自选角、打卡 |
| 领域 | 五大领域与《指南》要点、不设限与勇敢表达原则 |
| 故事 | 睡前 AI 互动故事提示词（可复制） |
| 成长 | 本机打卡统计与领域覆盖 |
| week | 本周节律预览（Next.js 站内 `/week/`） |
